Getting started

  1. Open BrowserSearch. A magnifier icon appears in your menu bar.
  2. Press ⌥Space anywhere. The search panel opens in the middle of your screen.
  3. The first time you search while Chrome or Safari is open, macOS asks whether BrowserSearch may control that browser. Click Allow.
  4. Type, pick a tab with ↑ ↓, press ↩.
Using Firefox? Open Settings… › Grant Accessibility… once. See Permissions.

Searching

Each tab is matched against its title, its URL and the browser's name.

  • Every word must match. gh pull finds “Pull requests · GitHub” but not “GitHub Home”.
  • Letters can be skipped. gthb still finds GitHub.
  • Exact text ranks first, and a match near the start of a title beats one near the end.
  • Add a browser name to narrow it down: safari docs.

With an empty search box the panel lists every open tab.

Keyboard

KeyAction
⌥Space (default)Open or close the panel
↑ / ↓Move the selection (wraps around)
↩Switch to the selected tab
EscClose the panel and return to what you were doing

You can also click a result. Clicking outside the panel closes it.

Browsers that aren't running are skipped. BrowserSearch never opens a browser just to search it.

Permissions

Automation (Chrome, Safari). Lets BrowserSearch read tab titles and URLs and switch tabs. macOS asks once per browser. Review it in System Settings › Privacy & Security › Automation.

Accessibility (Firefox only). Firefox has no scripting support for tabs, so BrowserSearch reads Firefox's tab bar the way assistive tools do, and clicks the tab you pick. Turn it on with Settings… › Grant Accessibility…, then enable BrowserSearch in System Settings › Privacy & Security › Accessibility.

Settings

Open from the menu bar icon › Settings…

  • Search shortcut. Click it and press a new combination. Esc cancels. Combinations another app already owns are refused.
  • Launch at login. Starts BrowserSearch quietly when you log in. If macOS asks for approval, click Open Login Items.
  • Permissions. Shows whether Firefox access is granted.
