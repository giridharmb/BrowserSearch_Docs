Troubleshooting

Pressing the shortcut does nothing
  1. Check that the magnifier icon is in your menu bar. If not, open BrowserSearch again.
  2. Open Settings…. A red note under the shortcut means another app owns it. Record a different one.
  3. Try choosing Search Tabs from the menu bar icon. If the panel opens, the problem is the shortcut, not the app.
Chrome or Safari tabs don't show up
  1. The browser must already be open; BrowserSearch never launches it.
  2. Open System Settings › Privacy & Security › Automation, find BrowserSearch and turn on the browser.
  3. If you clicked Don't Allow earlier and BrowserSearch isn't listed, run tccutil reset AppleEvents com.giridharmb.BrowserSearch in Terminal and search again to get the prompt back.
Firefox tabs don't show up

Grant Accessibility: Settings… › Grant Accessibility…, then turn on BrowserSearch in System Settings › Privacy & Security › Accessibility. The panel shows a reminder at the bottom while Firefox is open without access.

Why don't Firefox results show a URL?

Firefox doesn't let other apps read its tabs through scripting, so BrowserSearch reads the tab bar instead, which only has titles.
